# 🗂️ Microservicio Catálogo - VidaSalud

Gestión de la infraestructura física del centro de salud y oferta de prestaciones médicas.

## 🚀 Capacidades
- **Gestión de Boxes**: Registro, consulta, edición y control de disponibilidad de boxes médicos.
- **Catálogo de Prestaciones**: Definición de servicios clínicos habilitados para reserva.
- **Persistencia**: PostgreSQL (`vidasalud_catalog`).
- **Seguridad**: Validación de tokens JWT de Azure Entra ID.
- **Puerto**: `8081`.
