# 🖥️ Frontend VidaSalud

Portal web interactivo para pacientes, personal médico y administradores clínicos.

## 🚀 Tecnologías
- **React 19**
- **Vite 6**
- **Azure MSAL (OAuth 2.0 / OpenID Connect)** para autenticación Zero Trust.
- **Axios** configurado para consumir endpoints a través de **AWS API Gateway**.

## 👥 Roles Soportados
- `PACIENTE`: Reserva y consulta de citas médicas personales.
- `MEDICO`: Visualización de agenda y gestión de atenciones.
- `ADMINISTRATIVO`: Gestión integral de boxes y catálogo de prestaciones.
- `AUDITOR`: Supervisión de trazabilidad clínica y auditoría de eventos.
